# EndTask

Пункт «Завершить задачу» для панели задач Windows 10, как в Windows 11.

**Ctrl + правая кнопка мыши** по программе на панели задач открывает меню с пунктом
«Завершить задачу», который принудительно завершает процесс программы.

- Окна проводника только закрываются (иначе вместе с ними пропала бы панель задач).
- Для программ, запущенных от администратора, предлагается завершение через UAC.
- Приложения Microsoft Store завершаются через свой настоящий процесс, а не через ApplicationFrameHost.
- Значок в области уведомлений: автозапуск вместе с Windows и выход.

## Сборка

```
build.bat
```

Нужен только компилятор .NET Framework 4, который уже есть в Windows 10. Результат: `EndTask.exe`.

## Как это устроено

- Глобальный хук мыши (`WH_MOUSE_LL`) в отдельном потоке ловит Ctrl + ПКМ над `MSTaskListWClass`
  и не пропускает этот щелчок в проводник.
- Имя кнопки берётся через MSAA (`AccessibleObjectFromPoint`), например «Заголовок —1 запущенное окно».
- По имени ищется окно: сначала по заголовку, для сгруппированных кнопок — по названию программы
  (описание/продукт/имя exe).

Служебные ключи: `/probe <файл>` — отчёт о кнопках панели задач и найденных процессах,
`/demo <N>` — показать меню для N-й кнопки без щелчка.
